Hermes Link Bridge

Sends right-clicked link URLs to a local bridge server, which runs a shell command.

How it works (click to expand)
  1. Start the bridge server:
    python3 /path/to/bridge_server.py
  2. This extension adds "Send to Terminal" to the right-click menu on links.
  3. When you click it, the link URL is POSTed to the bridge server.
  4. The server runs whatever command you configured (via HERMES_LINK_COMMAND)

Example: Save links to a file

HERMES_LINK_COMMAND='echo %s >> ~/links.txt' python3 bridge_server.py

Example: Open link in curl and pipe output to less

HERMES_LINK_COMMAND='curl -sL %s | head -50' python3 bridge_server.py
